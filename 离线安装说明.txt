希腊离线漫游：手机安装与无网使用说明

一、推荐方式：HTTPS 安装 PWA（最可靠）

1. 在电脑上把整个项目文件夹上传到支持 HTTPS 的静态网站。推荐 GitHub Pages、Cloudflare Pages 或 Netlify。
2. 保持目录结构不变，入口可选择 mobile.html（手机）或 pc.html（电脑）。
3. 在手机浏览器打开 HTTPS 地址，例如：
   https://你的域名/mobile.html
4. 保持联网，等待页面顶部提示“离线包已就绪”。首次会下载约 104 MB 的地图插图、真实照片和语音。
5. Android Chrome：点右上角菜单，选择“安装应用”或“添加到主屏幕”。
   iPhone Safari：点“分享”，选择“添加到主屏幕”。
6. 安装完成后，打开飞行模式，再从主屏幕打开本应用测试。
7. 必须保留浏览器站点数据，不要清理该网站的缓存，否则离线包会丢失。

二、没有网站时：直接复制文件夹

1. 解压“希腊离线漫游-离线包.zip”。
2. 把整个文件夹复制到手机存储，必须保留 assets、scripts 等子文件夹及相对目录。
3. Android 可以尝试用 Chrome 打开 mobile.html。
4. iPhone 建议使用支持本地网页的“文件”类 App 或本地服务器 App。
5. 直接以 file:// 打开时，Service Worker 无法安装；部分浏览器可能限制本地音频读取，系统中文 TTS 会作为回退。

三、电脑本地使用

在项目目录执行：
npm start

然后打开：
http://127.0.0.1:4173

四、出行前检查

- 确认已经完整联网打开过 mobile.html。
- 确认顶部显示“离线包已就绪”。
- 测试地图缩放、列表、详情、图片和“听本段”。
- 开启飞行模式后重新打开一次。
- 不必依赖国外网络，应用不会请求在线地图或远程图片。
