# 希腊离线漫游

提供通用入口、PC 版和手机版：`index.html`、`pc.html`、`mobile.html`。PC 版适合宽屏地图和大图浏览，手机版固定单列、底部导航和逐站卡片。

面向中国游客前往希腊旅行的离线网页导览工具。应用不依赖在线地图、远程图片、在线字体或第三方内容接口，地图、景点数据、中文介绍、主题图集与预置中文讲解音频均随项目本地保存。

## 功能

- 地图视图：鼠标滚轮、双指手势、按钮缩放；拖动或键盘方向键平移；双击放大。
- 分级标注：低缩放显示城市聚合，中缩放显示景点，高缩放显示景点内关键物件；点击城市可放大探索。
- 列表视图：按雅典、德尔斐、梅黛奥拉等 10 个城市/地区分组，支持关键词搜索和分组展开。
- 景点详情：总览保持简洁，按游览路线展示核心点；每站包含顺序、路线提示、详细旅游词介绍、真实图片和独立语音按钮。
- 离线语音：35 个景点总览和 119 个核心游览点均包含独立预置中文 WAV 讲解，支持播放、暂停、停止、上一段、下一段和单点播放；预置音频不可用时可回退到设备系统中文 TTS。
- PWA：点击“缓存”按钮后缓存全部图片、语音和页面资源，顶部显示真实进度；完成后不再重复显示进度条，可用“清除缓存”释放空间。
- 本地真实图片：从 Wikimedia Commons 搜索并下载景点与核心游览物照片，保存作者、许可和来源信息；对少数缺少精确结果的条目使用同景点已授权照片并明确标注。

## 直接使用

最简单的测试方式是双击 `.\index.html`。页面、地图、数据、图片和音频均通过相对路径加载，使用 `file://` 打开也能完成大部分离线浏览与音频播放。

若需要 PWA 安装和完整离线缓存，请启动本地静态服务器：

```powershell
cd "."
npm start
```

然后访问：

```text
http://127.0.0.1:4173
```

首次打开时浏览器会在后台缓存约 104 MB 的逐站音频、真实图片和页面资源。缓存完成后，可以在浏览器菜单中选择“安装应用”或“添加到主屏幕”；之后即使国外无网络、弱网或飞行模式，也能从主屏幕打开。

## 项目结构

```text
index.html                    通用响应式入口
pc.html                       PC 独立入口
mobile.html                   手机独立入口
styles.css                    桌面和移动端响应式样式
data.js                       城市、景点、章节、坐标与子标注数据
app.js                        地图、列表、详情、图集和路由逻辑
audio-engine-v2.js            Web Audio 逐站播放、增益、进度和 TTS 回退
content-plus.js               景点深入阅读内容
subitem-plus.js               核心点路线顺序与逐点讲解
service-worker.js             PWA 离线缓存
manifest.webmanifest          安装信息与图标
scripts/serve.js              无依赖本地静态服务器
scripts/prepare-audio-text.js 从景点数据提取讲解文本
scripts/generate-audio.ps1    使用本机 Windows 中文语音生成 WAV
scripts/create-icons.ps1      生成 PWA 图标
assets/audio/paragraphs-v2/*.wav 154 段景点总览与逐站讲解音频
assets/audio/narration-text   可重新生成音频的中文文本
assets/icons                  本地 PWA 图标
```

## 重新生成内容

修改 `data.js` 后，先重新生成讲解文本，再在 Windows 上生成音频：

```powershell
node scripts\prepare-audio-text.js
powershell -ExecutionPolicy Bypass -File scripts\generate-audio.ps1
```

音频脚本使用 Windows SAPI 中文语音“Microsoft Huihui”或同语言的中文离线语音，输出 8 kHz、16 bit、单声道 WAV，以减小离线包体积。当前 154 个文件合计约 45 MB。

## 数据说明

地图为专门为本项目绘制的离线矢量底图，不是在线地图截图或在线瓦片。景点坐标用于地图定位与子项分层显示，属于旅行导览用途；现场开放时间、登岸许可、考古区围挡和宗教场所礼仪可能调整，应以当地公告为准。

内置内容覆盖用户要求的全部景点与子项，包括：

- 雅典：雅典卫城、雅典娜圣域、卫城博物馆、宪法广场、古罗马市集、蒙纳斯提拉奇广场、普拉卡老城区、菲洛帕波斯山、新古典主义三部曲、国家花园、大理石体育场、宙斯神庙、哈德良拱门、利卡维多思山。
- 德尔斐：德尔斐遗址、德尔斐考古博物馆。
- 梅黛奥拉：六座主要修道院。
- 帕特雷：圣安德烈教堂、罗马剧场、帕特雷城堡。
- 扎金索斯：沉船湾、蓝洞。
- 奥林匹亚：遗址、考古博物馆。
- 伯罗奔尼撒：帕拉米帝城堡、迈锡尼遗址、柯林斯遗址、柯林斯运河。
- 圣托里尼：伊亚小镇、红沙滩、黑沙滩、白沙滩、火山、费拉小镇、皮尔格斯小镇。

## 浏览器建议

推荐使用最新版 Chrome、Edge、Safari 或 Android Chrome。系统中文 TTS 的可用性和音色由设备决定；预置 WAV 不依赖设备语音包。iOS 对自动播放有限制，点击页面中的播放按钮即可开始，这是正常的安全策略。
